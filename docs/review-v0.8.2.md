## v0.6.2와의 비교

v0.8.1은 네이비·플럼 계열 UI와 4단계 작업 화면, 실행별 인용 상세 패널, 가격 비교/그룹 관측 분리, 당시 근거 문서와 보고서 맥락 보존, 실행 번호별 보고서 재출력을 추가했다. GitHub Pages 정적 배포와 Vercel 서버리스 배포 경로가 추가됐으며 서버리스 로그인·세션·CSRF·모의 조회 시험도 포함한다. 변경 파일 목록은 comparison-v062-v081.json 참조.

## 확인한 오류와 수정

1. **구버전 실행 정보 유실(높음)**: 최신 run.input이 있는 구버전 기록을 새 버전에서 재실행하면 이전 입력을 제거하면서 reportContext/citations를 보완하지 않았다. 당시 입력이 남아 있고 해시가 일치할 때만, 제거 전에 당시 보고서 맥락·인용을 보존한다. 현재 작업본으로 채우지 않으며 기존 보존본은 덮어쓰지 않는다. 원본 객체도 변이하지 않는다.
2. **과거 가격 ‘미입력’ 오표시(중간)**: 입력한 세대당 가격은 결과에 남아 있지만 전용면적이 없어 단가를 계산하지 못한 과거 기록을 미입력으로 표시했다. 가격 입력 여부와 단가 환산 가능 여부를 분리하여 남아 있는 원래 가격 문구를 표시한다.
3. **보고서 파일명과 본문 불일치(중간)**: 구버전 실행에 전체 입력만 남은 경우 현재 rec.title을 파일명으로 사용했다. 본문과 같은 당시 맥락에서 파일명 제목을 얻는다. 당시 정보가 없으면 ‘실행’으로 표시한다.
4. **손상 단계 값으로 화면 중단(중간)**: sessionStorage에 99·소수 등 범위 밖 값이 있으면 STEPS[step-1]이 없어 오류가 발생할 수 있었다. 저장 단계는 1~4 정수만 허용하고 나머지는 1단계로 복구한다. 뒤로/앞으로 이벤트도 소수를 거부한다.
5. **조회 이력 생략 안내 누락(낮음)**: 최근 30개 이력만 보존하면서 생략 여부를 표시하지 않았다. 전체 개수를 함께 보존하고 보고서에서 전체/보존 건수를 표시한다. 이전 기록의 전체 개수를 추정하지 않는다.

버전 표기는 package.json/package-lock.json에서 0.8.2로 변경했다. 의존성 버전·배포 설정·서버 인증 코드는 변경하지 않았다.

## 남은 범위

기존 API 구조와 4단계 UI를 보존했다. 자동 반경 그룹 선정/인과효과 추정은 추가하지 않았다. 이미 스냅샷이 사라진 과거 자료는 복원할 수 없다. 메타데이터 보완으로 이전 입력의 맥락을 남기므로 저장 용량은 약간 늘 수 있다. 서버리스 횟수 제한은 인스턴스별이며 분산 전체 제한은 아니다. 서버 임시 저장의 페이지 종료 시 비동기 저장 완료는 보장되지 않는다. 실제 배포/외부 API 검증은 별도다.

## 로컬 실행

Node >=22.13 <23에서:

```sh
npm ci --ignore-scripts
npm run typecheck
npm run build
npm test
npm start
```

http://localhost:5174/app 에서 수동/CSV/JSON 흐름으로 사용한다. API 키를 설정하지 않아도 이 흐름은 동작한다.

브라우저 검증 환경에서는 `npx playwright install chromium` 후 `npm run test:e2e`. 이미 설치된 Chromium은 PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH로 지정할 수 있다.

배포 인계는 CLAUDE_DEPLOY.md 참조. 기존 Archive·Render·협의체 운영 설정은 접근/수정하지 않았으며 실제 배포·push·키 설정을 하지 않았다.
