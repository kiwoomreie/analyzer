# v0.6 수동 확인 그룹 관측 분석

기준: apartment-location-price-analyzer-v0.5.2.zip (SHA-256 c215d759eefd09bb0d6633ba41ba6c1e3a0ff151ad7f6e6ed93623962626c394).

## 구현

기존 실거래 상세의 사건 전후 표를 수동 확인 영향권/비교군 패널로 확장했다. 새 탭·API·운영 설정은 추가하지 않았다. 사용자 기록 중 실제 일정의 일 단위 날짜만 선택하며 발표·착공·개통 등 기존 일정 유형을 그대로 사용한다. 예정 또는 월 단위 날짜에 임의 일자를 만들지 않는다.

전후 3/6/12개월, 단지별 그룹 체크, 중복 양측 제외, 전후 중위 단가(원/전용㎡)·표본·단지 수·면적 구간 수·변동률(%)·차이(%p), 월별 중위값과 건수를 표시한다. 월별 추이는 표이며 그래프는 미구현이다.

본건 면적 허용범위 안의 단지×고정 5㎡ 구간([80,85), [85,90) 등)에 양기간 거래가 모두 있어야 포함한다. 전 [기준일-N개월, 기준일), 후 [기준일, 기준일+N개월)이며 말일은 기존 날짜 함수로 처리한다. 동일 호실 반복매매 분석이 아니다. 거래 가중 중위값이므로 단지·세부 면적 구성비 영향은 남는다. 5㎡ 경계 양옆의 가까운 면적은 다른 구간으로 처리된다.

기간별 최소 표본은 max(3, 기존 minSample), 기본 10건이다. 미래 사건은 계산하지 않으며 미완료 관찰기간은 현재까지의 중위값·표본만 보여주고 변동률과 차이는 비워 둔다. 신고 지연, 미수집/부분 수집, 다른 사건 중첩, 가상 자료, 좌표 미확인과 직선거리 한계를 경고한다.

해제, 수동 제외, 같은 출처·ID의 사본/충돌, 정정 확인 필요 거래, 해제 대상 불확실성과 수동 제외가 겹친 묶음은 보수적으로 제외한다. v0.5.2의 기존 거래 대사·대표 비교분석은 변경하지 않았다.

## 저장 및 범위

`WorkingInputs.observation`에 설정을 저장한다. 기존 데이터에 이 필드가 없으면 읽을 때 기본 6개월/빈 그룹을 적용하며 기존 스냅샷·해시를 바꾸지 않는다. 새 패널은 현재 작업본에 즉시 반응하고 기존 분석 결과·보고서는 기존 실행 스냅샷 기준이다. 기존 보고서/요약의 전후 관찰은 이전 분석이며 새 그룹 분석 보고서 출력은 아직 통합하지 않았다. 새 설정은 기존 브라우저 저장·JSON 백업에 보존된다. CSV는 거래 입력 경로를 그대로 사용한다.

의도적으로 이번 범위는 수동 확인 그룹 우선이다. 사건 중심 좌표/반경 자동 그룹 선정, 지도에서 그룹 선택, 자동 비교군 추천, 자동 뉴스/고시 수집은 미구현이다. 좌표가 없어도 사용자 확인 그룹에 포함되므로 경고를 확인해야 한다. 자동 가격 보정·적정가격·예상 상승률·인과 효과는 산출하지 않는다.

## 실행

Node >=22.13 <23에서 프로젝트 폴더를 열어 다음을 실행한다. API 키 없이 수동/CSV/JSON 흐름으로 실행할 수 있다.

```sh
npm ci --ignore-scripts
npm run build
npm start
```

http://localhost:5174/app 에서 `examples/sample-data/demo-v06-observation-backup.json`을 백업 가져오기로 열고 실거래 상세를 펼친다. 가상 예제는 영향권 +20%, 비교군 +10%, 차이 +10%p다. 기본 6개월 설정과 최소 3건이 예제에 기록돼 있다. 실제 자료로 오인하지 말 것.

```sh
npm run typecheck
npm run build
npm test
npx playwright install chromium
npm run test:e2e
```

이미 설치된 Chromium을 사용할 때는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`에 실행파일 경로를 지정할 수 있다. `npm test` 통합시험은 빌드된 화면을 사용하므로 빌드 후 실행한다. 테스트의 가짜 키·모의 응답은 네트워크 API 호출 없이 시험 함수에만 주입된다. 실제 키는 설정하지 않았다. /launch 기본 비활성은 유지했다.

## v0.6.1 보완 (2026-11-19, v0.6 검토 지적 반영)

- **기존 기능 복원**: v0.6에서 지워졌던 실거래 상세의 ‘입지 사건 전후 관찰’ 표(발표 전후 건수·중위 단가·사분위)와 사건별 ‘선반영’ 설명을 되살렸다. 이 표는 마지막 분석 실행 기준(실행 번호 표시)이며, 새 그룹 패널은 그 아래에 별도로 둔다.
- **기준 구분·보고서 연결**: 그룹 관측 설정이 있으면 `withRun`이 같은 입력 스냅샷으로 `observeGroups`를 계산해 실행 결과(`result.groupObservation`)에 보관한다. 1페이지 요약 §2, 보고서 초안, 근거 부록 E(월별)에 실행 번호와 함께 출력한다. 패널은 현재 작업본 기준으로 즉시 갱신하고, 마지막 실행 값과 다르면 ‘보고서에는 실행 #n 값이 들어감 — 분석 다시 실행’ 안내를 표시한다. 설정이 없는 실행(또는 v0.6 이전 실행)은 보고서에 ‘설정 없음’ 한 줄만 쓴다.
- **선택 단지 소실 표시**: 선택했던 단지가 현재 거래 자료에 없으면(식별 정보 변경·거래 삭제) 경고하고, 패널에 ‘현재 거래 없음’ 행과 같은 이름의 다른 식별 단지 후보를 보여준다. 자동으로 다시 연결하지 않으며 사용자가 선택을 해제·재선택한다. 없는 단지는 ‘좌표 미확인’ 집계에서 뺀다.
- **표기**: 중위 단가를 만원/전용㎡로 표시하고(원 단위 계산), 결과 아래에 분석 기준일·단위·출처·자료 구분을 붙였다. 내부 식별키 대신 단지명과 시군구·법정동·지번을 보여준다.
- **같은 사건 다른 일정**: 선택 일정 외에 같은 사건의 다른 일정(예: 착공·발표)이 관찰기간에 있으면 경고한다.
- **경고 정리**: 상황별 경고(warnings)와 항상 적용되는 계산 기준·한계(notes)를 분리하고, notes는 접힌 영역에 둔다. ‘인과효과 아님’은 제목·차이 줄에 계속 표시한다.
- **자동 저장**: 화면 수정은 0.4초 묶음 저장이지만, 새로고침·탭 닫기·화면 이동·탭 숨김 때 대기분을 즉시 저장한다. 삭제·다른 저장소로 옮긴 직후에는 대기분을 취소해 옛 위치에 다시 쓰지 않는다.
- **시험 수정**: v0.6 브라우저 시험은 이미 이 브라우저에 저장된 기록에 없는 ‘이 브라우저에 저장’ 버튼을 눌러 실패했다. 자동 저장 완료 확인으로 바꿨다.
