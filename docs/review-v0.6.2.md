## 발견한 오류와 v0.6.2 수정

1. **보고서 실행 번호·입력 연결 오류(높음)**: 같은 입력으로 두 번 실행하면 첫 번째 동일 해시 기록을 선택해 최신 보고서에 실행 #1을 표시했다. 실행 결과 객체 일치를 우선하고, 복구된 결과의 해시 검색은 최신 기록부터 수행한다. 기존 다섯 재현 시험 중 이 항목도 원본에서 실패했고 수정 후 통과했다.
2. **과거 그룹명 오표시(높음)**: 과거 실행의 입력 스냅샷은 저장량 절약을 위해 제거되는데, 보고서가 현재 작업본의 그룹으로 과거 숫자를 설명했다. 새 관측 결과에 당시 선택 단지명을 저장했다. v0.6.1 이전 결과에 이름과 스냅샷이 모두 없으면 현재 이름을 추정하지 않고 확인 불가로 표시한다.
3. **현재 작업본/보고서 일치 안내 오류(중간)**: 숫자만 비교해 출처·기준일·경고가 바뀌어도 ‘같은 값’으로 안내했다. 전체 입력 해시의 변경 여부로 재실행 필요를 판단한다. React 실제 서버 렌더링으로 수정된 안내를 확인했다.
4. **표본 미산출 시 보고서 한계 누락(중간)**: 월별 행이 없으면 신고 지연 등 상시 안내도 보고서에서 빠졌다. 계산 한계를 월별 표와 무관하게 출력하며 초안에도 그룹 경고를 포함했다.
5. **좌표·관찰기간 경계 검사 오류(중간/낮음)**: lat/lng가 범위를 벗어나도 ‘기록 있음’으로 표시했다. 유한수 및 위도 ±90/경도 ±180 검사를 추가했다. 관찰창 종료일 당일 다른 일정은 거래의 반열린 기간 정의와 맞춰 중첩 경고에서 제외한다. 월 단위 정밀도로 경계 판단이 불확실하면 보수적으로 중첩 경고를 유지한다.
6. **통합 검사 순서**: 새 체크아웃에서 test:all이 화면 빌드 전에 통합시험을 실행했다. typecheck → build → 단위/통합 → E2E 순서로 정리했다. 의존성 버전은 변경하지 않고 패키지 버전 표기만 0.6.2로 맞췄다.

## 검증

- 지정 범위의 Node v22.23.5 사용. 의존성은 전용 폴더에서 npm ci --ignore-scripts로 설치했다.
- 첨부 v0.6.1 기준: 타입검사·빌드 통과, 단위/통합 114/114 통과.
- 추가한 초기 재현 5건: 첨부 원본에서 5건 실패 확인.
- 수정 후: 타입검사·빌드 통과, 단위/통합 **122/122 통과**. 신규 8건은 재실행 번호, 과거 그룹명, 미산출 보고서, 좌표, 종료 경계, 같은 숫자/다른 입력 화면 안내, 구버전 과거 결과, JSON 복구를 검증한다.
- 실제 React 서버 렌더링 시험 포함. 클릭·레이아웃·브라우저 자동 저장 검증을 대체하지 않는다.
- 브라우저 E2E: tests/e2e/v061.test.ts를 설치된 Chromium으로 실행 시도했으나 socket() Operation not permitted로 시작 실패. 후처리의 browser.close 오류까지 발생해 45초 제한으로 종료했다. **UI E2E 통과 또는 자동 저장 동작 검증 완료로 주장하지 않는다.** 이번 소스 수정 뒤 E2E 재실행은 이 환경 제한 때문에 미실행이다.
- v0.6.1 대비 shared/tradeMerge.ts, shared/analysis.ts, shared/runs.ts, server/config.ts, tests/unit/v052.test.ts, web/AnalysisView.tsx 원본 바이트 동일 확인. v0.5.2 취소·중복 대사 회귀시험도 전체 시험에 포함돼 통과했다.

## 남은 한계

수동 확인 그룹 방식이다. 사건 중심 좌표/반경 자동 그룹 선정과 월별 그래프는 아직 없다(월별 표 제공). v0.6.1에서 추가된 보고서 연결은 유지·수정했다. 고정 5㎡ 구간 경계, 거래 구성비 차이, 자료 완전성·신고 지연 때문에 인과 효과를 의미하지 않는다. 입력한 실제 일정의 사실 여부를 자동 확인하지 않는다. 과거 v0.6.1 결과에 사라진 스냅샷·그룹명은 복원할 수 없다.

실제 국토부/카카오 API, 운영 환경, 실제 협의체 연결은 미검증이다. /launch 기본 비활성은 유지했다. 서버 임시 저장은 비동기이므로 페이지 종료 시 원격 저장 완료를 보장하지 않는다. 주요 사용 흐름은 로컬 수동/CSV/JSON이다. 자동 저장 UI 동작은 사용 가능한 브라우저 환경에서 포함된 E2E로 재확인해야 한다.

## 실행

Node >=22.13 <23에서 새 폴더에 압축을 풀고 실행한다. API 키가 필요 없는 수동 흐름이다.

```sh
npm ci --ignore-scripts
npm run build
npm start
```

http://localhost:5174/app 에서 examples/sample-data/demo-v06-observation-backup.json을 가져온 뒤 ‘분석 다시 실행’을 누르면 현재 버전의 그룹 관측 보고서를 확인할 수 있다. 예제는 가상 자료다.

```sh
npm run typecheck
npm run build
npm test
npx playwright install chromium
npm run test:e2e
```

Archive 저장소·기존 Render·운영 설정은 접근/수정하지 않았다. 배포·push·실제 API 호출·키 설정 없이 전용 폴더에서 작업했다. 소스 ZIP에는 의존성 폴더·빌드물·DB·비밀 설정·캐시를 넣지 않았다.
