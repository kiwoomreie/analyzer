# 아파트 입지·가격 분석기

아파트 또는 사업지 **주소 1개**로 시작해 다음 세 가지를 확인하는 독립 웹 앱입니다.

1. 주변에서 어떤 입지 변화가 진행되고 있는지(교통·생활편의·개발사업·주변 입주 물량, 진행 단계·예정 시점)
2. 인근 유사 아파트 실거래와 비교할 때 검토가격을 뒷받침할 근거가 있는지(대표 비교단지 최대 5개, 선정 이유와 준공연도·거리·전용면적 차이)
3. 판단 전에 추가로 확인해야 할 사항(계획 지연, 경쟁 공급, 표본 부족, 비교단지와의 차이)

범위 밖: PF 현금흐름, 대출구조, LTV, 엑싯·회수 가능성 판단, 다른 자산유형. 기존 협의체(HAHANGCO/Archive, Render)와 역할을 분리하며, 그 코드·설정·데이터·비밀값을 읽거나 바꾸지 않습니다.

## 설치·실행

Node.js 22.13 이상(22.x)이 필요합니다(내장 `node:sqlite` 사용).

```bash
npm install            # 네트워크가 없는 개발 환경에서는 scripts/link-offline-deps.sh
npm run build          # 화면 번들 → dist/
npm start              # http://localhost:5174/app
```

| 명령 | 내용 |
|---|---|
| `npm run typecheck` | TypeScript 검사 |
| `npm test` | 계산·안전검사 단위 시험 + 서버 경계 통합 시험 |
| `npm run test:e2e` | Chromium 브라우저 시험(독립 사용 흐름, 삭제·재조회 반복, 저장 차단, 모바일 390px, 모의 공공 API, 대기 기능 회귀) |

공공 API 관련 시험은 모두 **모의 응답**(`tests/helpers/mockPublicApi.ts`)으로 수행합니다. 실제 국토교통부·카카오 API는 키가 없어 호출·검증하지 않았습니다.

## 사용 순서(독립 사용)

1. 첫 화면에 주소를 입력하고 **분석 시작**을 누릅니다. 전용면적·검토가격·준공(예정)연도·분양/준공 예정일은 ‘선택 입력’에서 필요할 때만 넣습니다.
2. 결과 1페이지: 요약 3블록(① 입지 변화 ② 가격 영향과 근거 ③ 주요 불확실성)과 대표 비교단지 표가 먼저 보입니다.
3. 자료 추가(접힌 상세 영역)
   - **실거래·비교단지 상세**: 실거래 CSV를 가져오거나, 키가 설정돼 있으면 ‘주소로 좌표·실거래 자동 조회’를 누릅니다. 단지별 거리·준공연도 확인값과 포함/제외 지정을 입력할 수 있습니다.
   - **입지 사건·근거 상세**: 사건과 일정 이력(발표일·적용일·수집일)·근거 문서·첨부를 기록합니다.
   - **입력·세부 설정**: 면적·검토가격·일정과, 접힌 ‘세부 설정’(반경·면적 범위·기간 등)을 고칩니다.
4. 입력을 바꾸면 **분석 다시 실행**을 누릅니다.
5. **이 브라우저에 저장** → 첫 화면 ‘저장한 분석’에서 다시 엽니다. JSON 내보내기·백업 복구도 가능합니다.
6. **보고서·변경 이력**에서 1페이지 요약+근거 부록, 확인 질문 초안, ‘~임.’ 문체 보고서 초안, 변경표를 Markdown·텍스트로 내려받거나 인쇄/PDF로 저장합니다.

예시 자료(모두 가상): `examples/sample-data/demo-nearby-trades.csv`, `examples/sample-data/demo-location-events.json`, 첫 화면의 ‘가상 데모로 사용해 보기’.

## 실거래 자료 처리

- **중복 제거**: 같은 CSV·API 자료를 여러 번 가져와도 같은 거래는 한 번만 집계합니다. 식별 기준은 ① 원천 거래 식별자(CSV의 `거래ID` 등, 있을 때) ② 없으면 단지 식별·전용면적·층·동·계약일·거래금액 복합 키입니다. 국토부 아파트 매매 API에는 거래 단위 공식 식별자가 없어 ②를 씁니다.
- **서로 다른 거래 보호**: 한 번에 받은 자료 안에서 복합 키가 완전히 같은 거래(같은 날 같은 층·면적·금액의 다른 호실 등)는 합치지 않고 순번을 붙여 각각 유지합니다.
- **해제·정정 대사**: 해제(취소) 표시는 원거래에 반영하고 이력을 남깁니다. 금액만 바뀐 건은 같은 출처 종류에서 1:1로 대응될 때만 정정으로 처리하고, 1:1이 아니면 합치지 않고 ‘정정 여부 확인 필요’로 집계합니다. 가져올 때마다 신규·중복·정정·해제 반영 건수를 표시합니다.
- **전 페이지 수집·대사**(공공 API): 시군구·월별로 응답의 전체 건수(totalCount)를 확인해 모든 페이지를 받고 수집 건수와 대사합니다. 한 페이지라도 실패하거나 건수가 맞지 않으면 ‘일부 수집 — 누락 가능’으로 표시하고 주요 불확실성에 올립니다.
- **반경 수집 범위**: 본건 좌표를 중심으로 반경·반경의 1/2 위 8방위와 중심, 모두 17개 지점의 시군구를 확인해 행정구역 경계 밖이라도 반경에 걸치는 시군구를 함께 수집합니다(지점 표본 방식이라 경계가 복잡하면 누락될 수 있음 — 화면에 표시).
- **비교단지**: 거리가 확인된(좌표 또는 사용자 입력 거리) 반경 내 단지 중 가까운 순으로 최대 5개를 대표로 선정합니다. 좌표·거리를 확인하지 못한 단지는 ‘확인 필요 후보’로 따로 표시하고 대표 통계에 넣지 않습니다. 같은 이름의 단지는 단지코드 또는 시군구·법정동·지번으로 구분해 표시합니다.

## 입지 사건·근거

- 입지 뉴스·고시 **자동 수집 기능은 없습니다.** 모든 사건·근거는 사용자 입력이며 ‘사용자 입력’으로 표시합니다.
- 근거 기록 수준: ‘사용자 입력(출처 미기재)’ / ‘출처 기재(원문 대조 기록 없음)’ / ‘공식 원문 대조 기록(사용자 기록, 자동 검증 아님)’. 마지막 수준은 공공기관 원문·문서번호 또는 첨부·페이지·발행일·‘원문 직접 대조’ 표시가 모두 있어야 하며, 사용자가 ‘사실로 기록’만 한 것으로는 공식 확인으로 표시하지 않습니다.
- 분석 기준일 이후에 처음 알려진 사건·근거는 분석에서 빼고 목록으로 보여줍니다. 기준일 이전에 취소가 알려진 공급은 물량 집계에서 뺍니다(기준일 이후에 취소가 알려졌다면 기준일 시점에는 유효한 공급으로 봅니다).

## 결과와 입력의 관계

- 각 결과는 **실행 당시 입력 스냅샷** 기준으로 화면·보고서에 표시합니다. 이후 입력이 바뀌면 ‘이전 결과 · 재분석 필요’를 표시하고, 거래를 모두 지워도 이전 결과는 깨지지 않고 그대로 보입니다.
- 자동 조회는 이미 입력한 본건 좌표·시군구·단지 거리·준공연도·사용자 제외 사유를 덮어쓰지 않습니다.

## 표시 원칙

- 금액은 내부에서 원으로 계산하고 만원으로 표시합니다. 면적은 전용㎡ 기준이며 1평=400/121㎡입니다.
- 숫자마다 분석 기준일·금액 단위·면적 기준·출처(가상/사용자 제공/공식 API)를 표시합니다.
- 관찰된 변화, 비교 차이, 미추정(인과효과)을 구분합니다. 적정가격·예상 상승률을 만들지 않습니다.
- 자료가 없으면 ‘보류’ 또는 ‘미산출’로 남깁니다. 0원으로 채우지 않고, 빈 기간을 가상 거래로 채우지 않습니다.
- 비교 가능한 단지가 5개보다 적으면 그만큼만 표시합니다.

## 저장

| 구분 | 위치 | 비고 |
|---|---|---|
| 저장 전 작업 | 브라우저 탭 세션 | 탭을 닫으면 사라짐 |
| 이 브라우저에 저장 | localStorage | 브라우저 데이터 삭제·다른 기기에서는 자동 복구 안 됨 → JSON 백업 권장. 저장소가 차단되거나 공간이 부족하면 ‘저장되지 않았습니다’ 오류와 JSON 내보내기 버튼을 표시(성공으로 처리하지 않음) |
| 백업 복구 | localStorage | 같은 식별자의 기존 기록은 덮어쓰지 않음(같은 내용은 건너뛰고, 다른 내용은 ‘복구 사본’으로 추가) |
| 서버 영구 보관 | 없음 | 새 앱 로그인·자료별 권한·삭제·복구 정책 결정 후 활성화 예정 |

## 환경변수(모두 선택)

| 이름 | 기본값 | 설명 |
|---|---|---|
| `PORT` / `HOST` | 5174 / 127.0.0.1 | |
| `DB_PATH` | `./data/location-analyzer.db` | 새 앱 전용 SQLite(세션·임시 자료) |
| `MOLIT_SERVICE_KEY` | 미설정 | 국토교통부 아파트 매매 실거래가(data.go.kr 15126469) — 실제 호출 미검증 |
| `MOLIT_APT_TRADE_ENDPOINT` | `https://apis.data.go.kr/1613000/RTMSDataSvcAptTrade/getRTMSDataSvcAptTrade` | 공식 문서로 최종 확인 필요. 호스트는 허용목록으로 고정 |
| `PUBLIC_DATA_MAX_MONTHS` | 12 | 한 번에 조회하는 최대 개월 수(시군구 최대 6곳, 시군구·월당 최대 20쪽, 단지 좌표 최대 80곳) |
| `KAKAO_REST_KEY` | 미설정 | 카카오 로컬 주소검색(주소→좌표·시군구) — 실제 호출 미검증 |
| `KAKAO_JS_KEY` | 미설정 | 지도 표시용(미설정 시 좌표 도식) |
| `LAUNCH_RECEIVER_ENABLED` | `false` | 협의체 시동 수신. 입력 규격·수신 주소 확정 전까지 **대기** |
| `COOKIE_SECURE` | `true` | 운영 HTTPS에서 반드시 true |

외부 호출은 `apis.data.go.kr`, `dapi.kakao.com` 두 호스트로만 합니다(https, 사설·메타데이터 주소 차단, 리디렉션 거부, 시간·크기 상한). 기존 협의체·Render의 키나 환경변수 그룹을 연결하지 마십시오.
